Agent Deck Insights

Agent Deck Insights

Agent Deck Insights sends the stats Agent Deck already recorded to the agent CLI you have installed, when you click, and shows each finding beside the recorded facts it cites.

See the plans →Agent Deck
What it does

Your stats, your CLI, your click.

Sent on an explicit click

Insights hands the Layer 1 stats Agent Deck recorded to the agent CLI you already have installed, with one prompt and a strict output schema. It happens when you click, and you see the exact bytes first.

Evidence you can check

Every finding carries evidence rows: a session, a stats key and a value. Each row resolves to a fact in Agent Deck’s own records.

An offline licence key

The licence is a signed key pasted into a setting and verified on your machine. There is no activation server and no account check.

No network call from the extension

The extension opens no connection. The CLI you run talks to its own provider, on your account, as it does whenever you use it.

The boundary

What it never does.

Never

  • reading transcripts
  • reading files
  • network calls from the extension
  • writing under any engine's data directory
