~/installabout 2 minutes

Up and running in three steps.

01

Install from the VS Code Marketplace, or from your terminal:

code --install-extension nvitlam.agent-deck
02

Click the Agent Deck icon in the VS Code sidebar. Your sessions appear.

03

Paste one hook blockoptional into your Claude Code or Codex settings for second-by-second updates. You paste it yourself, because Agent Deck never edits your settings. Guide →

~/faq
Can it control my agents?

No. It only watches.

Does it send my data anywhere?

No. It makes no network calls at all.

Why do I paste the hook myself?

Because read-only includes your settings. Agent Deck never writes to them.

Which versions does it support?
