~/what-is-it

Agent Deck shows what happened. Insights explains it.

Insights doesn't run any AI of its own. It hands the numbers Agent Deck already recorded to the Claude Code or Codex you already use, and shows you what comes back.

  • you getA report. Each finding gives one action, the cause, and the exact numbers behind it.
  • over timeEach finding is marked new, still happening, or fixed since your last report.
  • it costsYour plan, plus a little of your own Claude Code or Codex usage for each report.
~/what-it-finds

The habits that slow your agents down.

  • re-read loopThe same file read again and again, with nothing changed in between.
  • churn chainEdit, fail, edit again on the same file, and the failed calls in between.
  • context churnA huge tool result or a cold cache that suddenly makes every turn expensive.
  • compactionThe conversation was summarised to free up context, so earlier detail was summarised away.
  • silent subagentSubagents that did nothing, or whose results were never used.
  • stallCommands that block your agent for minutes, and waits nobody noticed.

~/faq
What exactly do I get for paying?

Reports. Each one is a short list of findings about your last 7 days of sessions: one action, the cause, and the numbers behind it. You can export any report, or open a follow-up session in your agent to ask about it.

Does Agent Deck need Insights?

No. Agent Deck is free and complete on its own. Insights only adds the reports.

Do I need Agent Deck?

Yes. Insights builds on the numbers Agent Deck records. Agent Deck is free.

Which agents does it work with?

Claude Code or Codex, installed on your machine and signed in to your account.

What does a report cost me?

Your plan, plus a little usage on your own agent account each time you run a report.

Is my code or chat history sent anywhere?

No. Only numbers, file names and agent names go to your own agent, and you see them before you click Send.

How do I cancel a subscription?

Through Polar, where you paid.
